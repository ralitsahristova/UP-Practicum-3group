# Оператори за цикъл

## Дефиниция
*Операторите за цикъл* се използват за изпълнението на един или няколко оператора многократно за различни стойности на техни параметри. Съществуват два вида итеративни процеси:

* **индуктивни**/директни:
  * цикличен процес, при който броя на повторенията е известен
* **итеративни**:
  * цикличен процес, при който броя на повторенията не е известен предварително и зависи от някакво условие
  
## Оператор за цикъл while

```
while (<условие>) {
    <...тяло на цикъла...>
}
```
1. Оценява се *<условие>*

2. Ако то е `true` се преминава към *<тяло на цикъла>*, след което се връщаме обратно в 1.

3. Ако *условието* е `false` *<тяло на цикъла>* се изпуска и цикъла приключва

Тъй като на първо място седи оценката/проверката на условието, този оператор също се нарича **оператор за цикъл с пред-условие**

Поради тази причина също така е възможно никога да не изпълним тялото на цикъла - ако *условието* е `false` още от самото начало, цикъла никога няма да се завърти.

## Оператор за цикъл do...while

```
do {
    <...тяло на цикъла...>
} while (<условие>);        //не забравяйте ; накрая на do...while
```
1. Изпълнява се *<тяло на цикъла>*

2. Оценява се *<условие>*

3. Ако то е `true` се връщаме обратно в 1.

4. Ако *условието* е `false` цикъла приключва

За разлика от `while`, `do...while` ни гарантира поне едно изпълнение на *<тяло на цикъла>*

Тъй като оценката/проверката на условието седи след тялото на цикъла, този оператор също се нарича **оператор за цикъл с пост-условие**

## Оператор за цикъл for
```
for (<инициализация>; <условие>; <корекция>) {
    <тяло на цикъла>
}
```

1. Изпълнява се *<инициализация>*

2. Оценява се *<условие>*
   * ако е `false`, цикълът приключва
   * ако е `true`, преминаваме към 3.

3. Изпълнява се *<тяло на цикъла>*

4. Изпълнява се *<корекция>*

5. Връщаме се към 2.

**Забележки**
* *<инициализация>* се изпълнява точно веднъж, в началото на цикъла

* както при `while` е възможно тялото на `for` да не се изпълни нито веднъж, ако условието поначало е `false`
* *<корекция>* се нарича така, защото обикновено в нея се модифицират данните, създадени в *<инициализация>*

## Jump statements
* оператор `break` - принудително прекратява изпълнението на цикъла

* оператор `continue`
  * в `while`: прескача всичко, стоящо след него в *<тяло на цикъла>* и изпълнява *<условие>*
  
  * в `for`: прескача всичко, стоящо след него в *<тяло на цикъла>*; изпълнява *<корекция>*; проверява *<условие>*

## Безкраен цикъл
Ако в *<условие>* на който и да е цикъл има израз, който никога не може да стане `false`, то цикълът няма да свърши никога - имаме **безкраен цикъл**

**Примери:**
```
while(true)
for(;;)
```

В такъв случай трявба да има нещо в *<тялото на цикъла>*, което да подсигури, че цикълът ще прекъсне в даден момент - *jump statements*
